# Smart City Network Simulation Using Cisco Packet Tracer

### Designing a Connected, Secure and Automated Smart City

A network simulation project demonstrating the integration of computer networking, Internet of Things (IoT) devices, and automation to create a connected smart city infrastructure using **Cisco Packet Tracer**.

## Project Overview

This project focuses on designing and simulating a smart city network that connects multiple zones through a centralised network infrastructure.

The system consists of a **Core Network, Server Network, Control Network, and three interconnected smart zones**. Each zone contains networking equipment and IoT devices that support monitoring, access control, and emergency response.

The objective is to demonstrate how modern networking technologies and IoT solutions can improve urban security, connectivity, and operational efficiency.

## Network Architecture

The architecture follows a hierarchical design, with a core router and multilayer switch connecting the central services and individual smart zones.

| Network Component | Description |
|---|---|
| Core Network | Central router and switch connecting all network segments |
| Server Network | IoT cloud, web, database, analytics and backup servers |
| Control Network | CCTV monitoring, emergency services and administration PCs |
| Zone 1 | Local network with IoT monitoring and security devices |
| Zone 2 | Independent smart zone with automation and access control |
| Zone 3 | Smart zone with connected surveillance and security devices |

Each zone includes a Cisco router, switch, and connected IoT components.

## How to Run the Project

1. Install **Cisco Packet Tracer**.
2. Clone or download this repository.
3. Open the `.pkt` project file in Cisco Packet Tracer.
4. Allow the simulated network devices to initialise.
5. Examine the core network, server network, control network, and three zones.
6. Use Packet Tracer's simulation tools to examine connectivity and packet flow.
7. Test configured IoT interactions, sensor conditions, and device communication.

## Testing and Validation

The project can be evaluated using the following methods:

- **Ping Testing:** Verify IP connectivity between supported devices.
- **DHCP Testing:** Check automatic IP address assignment.
- **Router Testing:** Verify communication across network zones.
- **IoT Testing:** Examine sensor triggers and connected-device responses.
- **Security Testing:** Test configured SSH access and device authentication.

*Note: Individual functions should be verified in the supplied Packet Tracer simulation before being considered fully operational.*
